# Bundled fonts

Static TTF files, licensed under the SIL Open Font License 1.1 (see the `OFL-*.txt` files in this folder).

| File                                                         | Source                                                                                                         |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| `BarlowCondensed-Bold.ttf`, `BarlowCondensed-ExtraBold.ttf`  | https://github.com/google/fonts/tree/main/ofl/barlowcondensed                                                  |
| `DMSans-Regular.ttf`, `DMSans-Medium.ttf`, `DMSans-Bold.ttf` | https://github.com/googlefonts/dm-fonts at commit `d0520ba03bd780f5dccb3024854463d44f699b78` (`Sans/Exports/`) |

The file name equals the PostScript name, so the same `fontFamily` string
(e.g. `BarlowCondensed-ExtraBold`) works on iOS, Android and web.
